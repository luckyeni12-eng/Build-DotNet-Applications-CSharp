# Build .NET Applications with C#

This repository contains my completed work for the Build .NET Applications with C# assignment.

## Technology

- C#
- .NET 8 LTS
- ASP.NET Core
- Visual Studio Code
- C# Dev Kit
- REST Client
- NuGet

## Projects

### Module 1 — First C# Code

Contains examples of basic C# syntax, variables, operators, conditions, arrays, loops, and methods.

### Module 2 — Introduction to .NET

Contains a basic .NET console application demonstrating the .NET environment.

### Module 3 — Dependencies

Contains a .NET application using the Humanizer NuGet package.

### Module 4 — Debugging

Contains a C# application used to practice breakpoints and debugging in Visual Studio Code.

### Module 5 — Files and Directories

Contains a C# application that reads sales files and generates a Sales Summary report.

### Module 6 — Pizza Web API

Contains an ASP.NET Core controller-based REST API implementing CRUD operations for pizzas.

## Additional Assignment Work

An additional Pizza named BBQ Chicken was added to the Pizzas list.

A GenerateSalesSummary function was added to calculate sales totals and create a Sales Summary report.
